CareerGuide | Discover

Helping young people find opportunities that require no previous work experience

I built the first Discover prototype with HTML, CSS and JavaScript. It includes live search, filters by opportunity type and deadline sorting. Someone looking for an apprenticeship can narrow the listings and see which applications close soonest.

Portfolio Site

Building a home for my projects and documenting what I learn along the way

I built this portfolio from scratch with HTML and CSS. I used CSS Grid to give the project feed the most space, with a project directory on the left and my skills roadmap on the right. The feed gives me somewhere to share screenshots, explain my decisions and show how each project changes over time.
